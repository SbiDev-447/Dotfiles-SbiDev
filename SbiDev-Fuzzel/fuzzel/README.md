## Usage

1. Open your fuzzel.ini file, found in $XDG_CONFIG_HOME/fuzzel/ (defaulting to $HOME/.config/fuzzel/fuzzel.ini if $XDG_CONFIG_HOME is unset).

2. Remove existing [color] section if there is one.

3. Include the flavor and accent combination of your choice from themes/ into your configuration file using include=<path-to-your-theme-file> in the main section scope of fuzzel.ini. (if you are using Fuzzel >= 1.10) or copy the contents of one of the files (if you are using Fuzzel < 1.10).

4. Invoke fuzzel using a keybinding or from the terminal.
